# 10-Class Java Programming Plan

**Duration:** 10 hours · 1 hour per class · 2 weeks (5 classes per week)

| Class | Topics to Cover | Practical Program |
| :---: | :--- | :--- |
| **1** | Java introduction, JDK, JVM, program structure, Hello World, C vs Java | Print messages and understand program execution |
| **2** | Primitive data types, variables, operators, type conversion | Simple calculator |
| **3** | `if-else`, `switch`, `for`, `while`, `do-while` | Marks grading and multiplication table |
| **4** | Classes, objects, constructors, methods | Student class with details and marks |
| **5** | Object references, class-type variables, `null`, method overloading, `static` | Student counter and overloaded calculator methods |
| **6** | `Scanner`, getters, setters, `final`, access modifiers, encapsulation | Student registration program |
| **7** | Packages, imports, Java library packages, arrays, and multidimensional arrays | Student marks and matrix operations |
| **8** | Strings, String methods, `StringBuffer`, `StringTokenizer` | Text processing program |
| **9** | `ArrayList`, `Vector`, `LinkedList`, `Iterator`, `ListIterator` | Student record management |
| **10** | Revision, integrated practical, assessment, and doubt clearing | Console-based student management program |
